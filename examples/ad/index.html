nice2have-printer turns one HTML file and one CSS file into an exact DIN A0 PDF – checked, vector-sharp and ready for the print shop. No build step. No npm packages.

Three steps to print

  1. Write Lay out the content in index.html, style it in canvas.css. Every size is a multiple of --u.
  2. Check npm run shot renders a full-size screenshot and reports format, overflow and fonts.
  3. Print npm run pdf writes one exact A0 page, ready for the print shop.
~/my-poster
$ npm run shot
Format:      841 × 1189 mm OK (A0)
Free space:  Features: 0 mm
Fonts:       Poppins 400 · 500 · 600 · 700
Screenshot:  shot.png (3179 × 4494 px)

$ npm run pdf
PDF:         canvas-a0.pdf
             1 page · 841.0 × 1189.2 mm

Exactly A0

841 × 1189 mm on one page. Every export is checked against the format.

Zero dependencies

No npm install, no build, no dev server. Just Node 22 and the browser you already have.

Vector-sharp

Text, SVG and CSS stay vector, fonts are embedded. Only photos are pixels.

Catches mistakes

Clipped content, elements past the edge, missing images and fonts – reported before you print.

Any DIN format

A0 to A4, portrait or landscape: change the three values marked FORMAT.

Runs everywhere

Windows, macOS and Linux. Finds Chrome, Chromium or Edge on its own – or set CHROME.
